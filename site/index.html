How it ranks

A file is important when other files import it. Score per file:

SignalWeightSource
Import in-degree (refs)0.45Go blocks, Python, JS/TS, Rust, Ruby
Symbol count0.25Regex, first 200 lines
Size0.15Bytes, log scale
Symbol density0.05Symbols per byte

Token estimate is bytes/4. Budget keeps top-N by score, always keeps rank 1.

Flags

FlagEffect
--budget NMax output tokens (default 4000, 0 = unlimited)
--fullAll files, no truncation (includes tests, vendor)
--jsonMachine-readable, same rank order
--indexSearchable HTML page, no server
-o FILEWrite to file
--no-gitignoreInclude ignored files (warning: huge)
$ repomap --json . | head -c 300

Architecture

cmd/repomap/main.go — flags, budget wiring, output routing internal/mapx/ walk.go — walk + parallel extract + ref index symbols.go — regex symbol patterns per language rank.go — Budget() truncation (keeps rank 1) render.go — tree / JSON / HTML renderers gitignore.go — stdlib .gitignore subset
